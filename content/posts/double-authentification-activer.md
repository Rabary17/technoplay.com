***Un mot de passe seul peut être deviné, volé ou récupéré dans une fuite de données. La double authentification ajoute une deuxième preuve, pour que ton compte reste à toi, même si quelqu'un connaît ton mot de passe.***

<div class="essentiel">

**L'essentiel en 30 secondes**

- La double authentification demande un deuxième élément en plus du mot de passe, par exemple un code.
- Active-la d'abord sur ton adresse mail, puis sur tes comptes bancaires et réseaux sociaux.
- Garde des codes de secours hors ligne, pour ne pas être bloqué.

</div>

Elle repose sur une idée simple : prouver qui tu es avec deux éléments différents. Le mot de passe est le premier. Le second peut être un code envoyé sur ton téléphone, généré par une application, ou confirmé par une notification.

## Comment l'activer

Chaque service a son menu, souvent nommé « sécurité » ou « connexion ». Cherche l'option de validation en deux étapes, puis suis les indications. La plupart demandent de scanner un code avec une application d'authentification, puis de saisir un code à usage unique pour confirmer.

Commence par ton adresse mail, car elle sert souvent à réinitialiser les autres comptes. Passe ensuite aux services bancaires, puis aux réseaux sociaux.

<div class="exemple">

**Un exemple concret**

Une personne active la double authentification sur sa messagerie. Quelques jours plus tard, quelqu'un tente de se connecter avec son mot de passe. Le service demande le code envoyé sur le téléphone, et l'accès est refusé. La personne reçoit une alerte et change son mot de passe.

</div>

<div class="attention">

**Méfie-toi des faux codes**

Un message qui te demande de transmettre un code reçu par SMS est une arnaque. Un service légitime ne te demande jamais de lui donner ce code.

</div>

<div class="lexique">

**Les mots à connaître**

- **Authentification** : vérification de l'identité d'une personne qui se connecte.
- **Code à usage unique** : code temporaire, valable pour une seule connexion.
- **Code de secours** : code fourni à l'activation, pour récupérer ton compte si tu perds ton téléphone.

</div>

## Questions fréquentes

### Un SMS est-il assez sûr ?

C'est mieux que rien, mais une application d'authentification est généralement plus solide. Choisis la méthode proposée qui te paraît la plus fiable.

### Que faire si je perds mon téléphone ?

Utilise les codes de secours enregistrés à l'activation. Ne les garde pas sur le téléphone lui-même.

### Faut-il l'activer sur tous les comptes ?

Commence par les plus importants. La messagerie, la banque et les comptes qui contiennent des données personnelles sont prioritaires.
