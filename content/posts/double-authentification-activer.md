<div class="essentiel">

**L'essentiel en 30 secondes**

La double authentification ajoute une deuxième preuve d'identité après ton mot de passe, par exemple un code reçu sur ton téléphone. Active-la d'abord sur ta messagerie, puis sur tes comptes bancaires.

</div>

Un mot de passe seul peut être deviné, volé ou récupéré dans une fuite de données. La double authentification ajoute une deuxième preuve, pour que ton compte reste à toi, même si quelqu'un connaît ton mot de passe.

## C'est quoi, concrètement ?

Le principe repose sur deux éléments différents. Le mot de passe est le premier : quelque chose que tu connais. Le second peut être un code envoyé par SMS, généré par une application d'authentification, confirmé par une notification, ou vérifié par une clé physique. On parle aussi de **validation en deux étapes** ou de **2FA**.

Pense à un coffre-fort à deux serrures, qui demandent chacune une clé différente. Voler une seule clé ne suffit plus à l'ouvrir.

<div class="exemple">

**Un exemple concret**

Une personne active la double authentification sur sa messagerie. Quelques jours plus tard, quelqu'un tente de se connecter avec son mot de passe, probablement récupéré dans une fuite de données ailleurs. Le service demande le code envoyé sur le téléphone, et l'accès est refusé. La personne reçoit une alerte de tentative de connexion et change son mot de passe par précaution.

</div>

## Comment l'activer, pas à pas

1. **Ouvre les réglages de sécurité du service.** Cherche un menu « Sécurité », « Connexion » ou « Confidentialité ».
2. **Trouve l'option de validation en deux étapes.** Elle porte parfois le nom « 2FA », « authentification à deux facteurs » ou « vérification en deux étapes ».
3. **Choisis la méthode proposée.** Une application d'authentification scanne un code QR affiché à l'écran, puis demande un code à usage unique pour confirmer l'activation.
4. **Enregistre les codes de secours.** Le service t'en fournit une liste, à garder hors ligne, imprimée ou notée ailleurs que sur ton téléphone.
5. **Teste une déconnexion et reconnexion** pour vérifier que tout fonctionne avant d'en avoir vraiment besoin.

Commence par ton adresse mail, car elle sert souvent à réinitialiser les autres comptes. Passe ensuite aux services bancaires, puis aux réseaux sociaux.

## Lequel choisir selon ton cas ?

| Méthode | Niveau de sécurité | Ce qu'il faut savoir |
|---|---|---|
| Code par SMS | Correct | Simple, mais vulnérable si ta ligne téléphonique est détournée |
| Application d'authentification | Bon | Fonctionne même sans réseau mobile, recommandée par défaut |
| Notification à valider | Bon | Pratique, mais clique seulement si tu es bien à l'origine de la connexion |
| Clé physique de sécurité | Très bon | Idéale pour les comptes les plus sensibles, demande d'acheter la clé |

Pour la majorité des comptes, une application d'authentification suffit largement. Garde la clé physique pour ta messagerie principale ou un compte professionnel sensible.

<div class="attention">

**Méfie-toi des faux codes**

Un message qui te demande de transmettre un code reçu par SMS est une arnaque. Un service légitime ne te demande jamais de lui donner ce code : la technique est décrite dans notre article sur [les arnaques par SMS](/arnaques-sms-reconnaitre/).

</div>

## Les erreurs à éviter

- **Activer la double authentification, puis perdre les codes de secours.** Range-les dans un endroit sûr, jamais uniquement sur le téléphone concerné.
- **Communiquer un code reçu à quelqu'un qui le demande.** Aucun service légitime n'a besoin que tu le lui dises, par téléphone ou par message.
- **S'arrêter à un seul compte.** La messagerie, la banque et les comptes qui contiennent des données personnelles sont prioritaires, mais chaque compte important mérite cette protection.
- **Garder un mot de passe faible en pensant que la double authentification suffit.** Les deux se complètent : choisis aussi [un bon mot de passe](/choisir-bon-mot-de-passe/) ou utilise [un gestionnaire de mots de passe](/gestionnaire-mot-de-passe-gratuit/).

## Les mots à connaître

<div class="lexique">

- **Authentification** : vérification de l'identité d'une personne qui se connecte.
- **2FA** : abréviation anglaise pour l'authentification à deux facteurs.
- **Code à usage unique** : code temporaire, valable pour une seule connexion.
- **Code de secours** : code fourni à l'activation, pour récupérer ton compte si tu perds ton téléphone.
- **Clé de sécurité** : petit appareil physique qui sert de second facteur d'authentification.

</div>

## Questions fréquentes

**Un SMS est-il assez sûr pour la double authentification ?**
C'est mieux que rien, mais une application d'authentification est généralement plus solide. Choisis la méthode la plus fiable parmi celles proposées par le service.

**Que faire si je perds mon téléphone ?**
Utilise les codes de secours enregistrés à l'activation. Ne les garde jamais uniquement sur le téléphone lui-même, mais imprimés ou notés ailleurs.

**Faut-il l'activer sur tous les comptes ?**
Commence par les plus importants : la messagerie, la banque et les comptes qui contiennent des données personnelles. Étends ensuite à tes autres comptes sensibles.

**La double authentification protège-t-elle contre le phishing ?**
Elle réduit le risque, mais ne l'élimine pas totalement. Apprends aussi à [reconnaître un faux message](/reconnaitre-faux-message-phishing/) pour ne jamais saisir ton code sur un faux site.
