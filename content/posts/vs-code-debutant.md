***VS Code est un éditeur de code gratuit, utilisé par une grande partie des développeurs. Il colore ton code, te suggère des mots et signale tes erreurs avant même que tu lances le programme.***

<div class="essentiel">

**L'essentiel en 30 secondes**

- VS Code est un **éditeur de code** gratuit, disponible sur Windows, Mac et Linux.
- Il colore le code, suggère des mots et signale les erreurs directement dans le texte.
- Des **extensions** ajoutent la prise en charge de nombreux langages et outils.

</div>

Un éditeur de code n'est pas un traitement de texte. Il n'ajoute pas de mise en forme invisible, et il affiche les fichiers exactement tels qu'ils sont. C'est ce qui permet de les lire et de les corriger sans mauvaise surprise.

## C'est quoi, concrètement ?

VS Code, pour Visual Studio Code, est un **éditeur de texte spécialisé** dans l'écriture de code. Développé par Microsoft, il est gratuit et fonctionne sur les trois systèmes d'exploitation courants. Contrairement à un simple bloc-notes, il comprend la structure de ton code. Il colore les mots-clés, repère les erreurs de syntaxe et propose des suggestions pendant que tu tapes.

<div class="exemple">

**Un exemple concret**

Une étudiante ouvre son premier fichier HTML dans VS Code. L'éditeur colore les balises et lui signale une **balise non fermée**, avec un soulignement rouge. Elle corrige l'erreur en quelques secondes, sans avoir à chercher pendant une heure dans son code.

</div>

## Comment l'installer et le prendre en main, pas à pas

1. Télécharge VS Code depuis le site officiel de Microsoft, en choisissant la version correspondant à ton système.
2. Installe-le comme n'importe quel logiciel, en gardant les réglages proposés par défaut.
3. Ouvre un dossier de projet depuis le menu Fichier, plutôt qu'un fichier isolé : VS Code affiche alors tous les fichiers liés.
4. Installe l'**extension** correspondant au langage que tu apprends, pour profiter des couleurs et des suggestions adaptées.
5. Active l'enregistrement automatique si tu veux éviter d'oublier de sauvegarder tes modifications.
6. Choisis une taille de police confortable, et un thème clair ou sombre selon ce qui te fatigue le moins les yeux.

## Les zones à connaître

La **barre latérale** liste les fichiers du projet ouvert. La zone centrale affiche le contenu du fichier en cours. Le **terminal**, en bas de l'écran, permet de lancer des commandes sans changer de fenêtre. Les onglets, en haut, permettent de passer d'un fichier à l'autre rapidement.

<div class="attention">

**Ne lance pas n'importe quel code**

Une extension ou un script téléchargé sans vérification peut être dangereux. Installe uniquement des extensions connues, avec un nombre d'installations élevé, et lis leurs avis avant de les activer.

</div>

## Les erreurs à éviter

La première erreur est d'ouvrir un seul fichier au lieu du **dossier complet** du projet, ce qui prive VS Code de plusieurs fonctions utiles. La deuxième est d'installer trop d'extensions dès le début, ce qui ralentit l'éditeur sans réel bénéfice. La troisième est d'ignorer les soulignements rouges ou jaunes, qui signalent souvent une vraie erreur à corriger.

<div class="lexique">

**Les mots à connaître**

- **Éditeur de code** : logiciel qui facilite l'écriture et la lecture du code.
- **Extension** : module qui ajoute une fonction à l'éditeur.
- **Terminal** : fenêtre qui permet de taper des commandes.
- **Coloration syntaxique** : affichage en couleur selon la nature de chaque mot du code.

</div>

## Questions fréquentes

### VS Code est-il difficile à utiliser ?

Non, il a beaucoup de menus, mais tu peux commencer avec quelques fonctions seulement : ouvrir un dossier, éditer un fichier, enregistrer.

### Faut-il payer pour le logiciel ?

Non, VS Code est gratuit. Certaines extensions peuvent avoir leurs propres conditions, à vérifier avant de les installer.

### Peut-on utiliser VS Code avec Git ?

Oui. L'éditeur propose une interface intégrée pour suivre les modifications et créer des commits, sans ligne de commande.

### Quelle extension installer en premier ?

Celle qui correspond au langage que tu apprends. Par exemple, une extension Python si tu apprends Python, ou une extension dédiée au HTML et au CSS.
