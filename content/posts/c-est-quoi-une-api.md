***Quand une application affiche la météo ou un itinéraire, elle va souvent chercher l'information ailleurs. L'API est le passage qui organise cet échange entre deux logiciels.***

<div class="essentiel">

**L'essentiel en 30 secondes**

- API signifie interface de programmation. C'est un ensemble de règles pour échanger avec un logiciel.
- Une application demande une information, l'API la transmet dans un format défini.
- Une API a des règles d'accès : certaines sont gratuites, d'autres demandent une clé ou un abonnement.

</div>

Imagine un serveur de restaurant. Tu ne vas pas en cuisine, tu passes ta commande à travers lui. L'API joue ce rôle : elle reçoit la demande, la transmet au bon endroit, puis rapporte la réponse.

## Pourquoi c'est pratique

Une API évite de réinventer la roue. Une application de cartes peut utiliser les données d'un fournisseur, sans les recréer. Un site de voyage peut afficher des prix d'hôtels sans les produire lui-même. Chacun se concentre sur son métier.

<div class="exemple">

**Un exemple concret**

Une application de sport affiche la météo du jour. Elle envoie une demande à un service météo, en indiquant la ville. Le service répond avec les températures prévues. L'application les affiche dans son écran, sans savoir comment elles ont été calculées.

</div>

<div class="attention">

**Protège tes clés d'accès**

Une clé d'API est un secret. Si elle est publiée dans un code partagé en ligne, quelqu'un peut l'utiliser à tes frais. Garde-la hors du code public.

</div>

<div class="lexique">

**Les mots à connaître**

- **API** : règles qui permettent à deux logiciels d'échanger.
- **Requête** : demande envoyée à une API.
- **Clé d'API** : identifiant secret qui autorise l'accès à un service.

</div>

## Questions fréquentes

### Une API est-elle un logiciel ?

Pas exactement. C'est un ensemble de règles et d'accès, mis en place par un logiciel pour que d'autres puissent l'utiliser.

### Faut-il savoir programmer pour utiliser une API ?

Il faut un peu de code pour l'appeler depuis un programme. Certaines plateformes proposent aussi des outils sans code.

### Une API est-elle toujours gratuite ?

Non. Beaucoup offrent un usage gratuit limité, puis un tarif selon le volume. Lis toujours les conditions.
