***Écrire une page web est souvent le premier vrai pas vers la programmation. Tu verras ton texte prendre forme dans le navigateur, et c'est une récompense immédiate.***

<div class="essentiel">

**L'essentiel en 30 secondes**

- Une page web repose sur le HTML, qui structure le contenu.
- Le CSS ajoute les couleurs et la mise en page.
- Un simple éditeur de texte et un navigateur suffisent pour commencer.

</div>

Une page web est un fichier lu par le navigateur. Le HTML indique ce qu'il y a dans la page : un titre, un paragraphe, une image. Le CSS indique comment cela s'affiche : les couleurs, les tailles, les espaces.

## Les outils nécessaires

Il te faut un éditeur de texte, qui peut être un logiciel dédié au code, et un navigateur. Crée un dossier pour ton projet, puis un fichier nommé index.html. Ouvre-le ensuite dans le navigateur par un double clic : tu vois immédiatement le résultat.

## Ta première page, étape par étape

1. Écris la structure de base : une déclaration de type, une balise html, un titre dans l'en-tête.
2. Ajoute un titre principal et un paragraphe de présentation.
3. Insère une liste à puces avec tes centres d'intérêt.
4. Enregistre, puis rafraîchis la page dans le navigateur.
5. Ajoute ensuite une couleur de fond avec une feuille de style simple.

<div class="exemple">

**Un exemple concret**

Une personne crée une page qui présente son club de lecture. Elle écrit le nom du club en titre, une phrase d'accueil, puis la liste des prochains livres. Elle ajoute une couleur de fond douce. Sa page tient dans un seul fichier, et elle la partage à ses amis.

</div>

<div class="attention">

**Enregistre souvent**

Beaucoup de débutants oublient d'enregistrer le fichier avant de rafraîchir la page. Si rien ne change, vérifie d'abord la sauvegarde.

</div>

<div class="lexique">

**Les mots à connaître**

- **HTML** : langage qui structure le contenu d'une page web.
- **CSS** : langage qui décrit l'apparence de la page.
- **Balise** : mot entre chevrons qui indique le rôle d'un élément.

</div>

## Questions fréquentes

### Faut-il payer un hébergement pour une première page ?

Non, tu peux la tester sur ton ordinateur. Pour la mettre en ligne, il faudra un hébergement, parfois gratuit, à choisir avec soin.

### Dois-je connaître JavaScript tout de suite ?

Non. Le HTML et le CSS suffisent pour une première page. JavaScript ajoute ensuite des comportements interactifs.

### Mon navigateur affiche une erreur, que faire ?

Vérifie les balises ouvertes et fermées, ainsi que les guillemets. La plupart des erreurs viennent d'un oubli de ce type.
